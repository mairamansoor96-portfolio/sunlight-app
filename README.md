# Sunlight

*Looks great on your monitor. Let's go outside.*

Sunlight shows designers their interfaces in the conditions real users live in: bright sun, dim rooms, missing reading glasses, colour blindness. Drop in a screenshot, pick a circumstance, and wipe between before and after.

It runs entirely in the browser. Your screenshot never leaves your device.

- Design spec: [SPEC.md](SPEC.md)
- Build plan and progress: [PLAN.md](PLAN.md)

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static site in out/
npm test           # unit tests
npm run test:e2e   # end-to-end tests (after build)
```
